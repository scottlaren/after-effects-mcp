# After Effects MCP

Форк [a-y-ibrahim/after-effects-mcp](https://github.com/a-y-ibrahim/after-effects-mcp)
с новой панелью **MCP Bridge** для Windows.

## Что исправлено

Исходная ScriptUI-панель запускает проверку команд через `app.scheduleTask`
каждые 250 мс, даже когда команд нет. При открытом диалоге AE может отклонить
такой запуск с ошибкой **Cannot run a script while a modal dialog is waiting
for response** ещё до выполнения первой строки скрипта.

Новая CEP-панель проверяет командный файл вне движка ExtendScript. Во время
простоя скрипты в AE не запускаются. У команд есть срок действия: запрос,
задержавшийся за диалогом, не должен начать изменять проект после истечения
этого срока. Команды с неопределённым результатом автоматически не повторяются.

В одной строке панели — Command History и три квадратные кнопки с иконками:
Pause/Play, Export и Clear.
Статус находится внизу рядом с Connection details. Текст записей использует шрифт 12 px:
выполняющееся действие серое с мягким бликом, завершённое — белое, ошибка — красная.
Значков статуса нет.
Новые действия появляются сверху, с временем, длительностью и ошибками. Одна запись на команду
обновляется по мере выполнения. Вместо технических имён показываются названия
действий; для произвольного скрипта ассистент обязан передать конкретное `description`
на выбранном языке. Переключатель **EN / RU** находится в **Connection details → Command language**.
По умолчанию выбран английский; выбор сохраняется между запусками и влияет только
на новые команды. Интерфейс и технические ошибки остаются на английском, старая история не переводится.
Ассистент читает настройку через `check-bridge` с `settingsOnly: true` без обращения к AE.
Подпись описывает действие: «Inspect layer timing and expressions» или «Проверить тайминг и выражения слоёв».
Сервер и панель отклоняют пустые подписи, заглушки вроде «Run script» или «Запустить скрипт»
и подписи на другом языке до запуска, предлагая ассистенту исправить описание.
Имена объектов сохраняются в двойных кавычках. Это проверка символов, не автоматический перевод.
После обновления нужно переподключить MCP в клиенте: переоткрытие панели не обновляет
инструкции уже запущенного сервера.
Последние 200 записей хранятся только в памяти текущей сессии.
При повторном открытии панели история начинается заново.
Прокрутки нет: увеличение высоты панели открывает больше записей. Export сохраняет
все доступные записи сессии, включая скрытые, в `.txt` через диалог выбора файла.
При ширине панели до 280 CSS px длительность скрывается, чтобы не занимать отдельную строку;
при расширении снова появляется. В экспорте длительности остаются всегда.

Сохранены 57 инструментов исходного MCP и исправление передачи Unicode/emoji.

## Установка на Windows

Проверено с After Effects 25.3.2 и Node.js 24.13.1.

```powershell
git clone https://github.com/scottlaren/after-effects-mcp.git
cd after-effects-mcp
npm ci
powershell -NoProfile -File .\install-modal-safe.ps1
```

Установщик сохраняет резервные копии и включает режим разработчика CEP
(`PlayerDebugMode=1` для CSXS 11/12), необходимый для локального неподписанного
расширения. Права администратора не нужны.

1. В настройках AE включить **Allow Scripts to Write Files and Access Network**.
2. Сохранить проект и перезапустить AE.
3. Открыть **Window → Extensions → MCP Bridge** и оставить панель открытой.
4. В MCP-клиенте указать запуск `node` с абсолютным путём к `build/index.js`
   из этого форка. Перезапустить подключение клиента.
5. Запустить `check-bridge`: ожидаются `transport: cep`, `versionMatch: true`
   и версия `1.13.0-modal-safe.1`.

Старую панель `mcp-bridge-auto.jsx` открывать больше не нужно. Пакет исходного
проекта из npm не содержит изменений этого форка.

## Проверки и ограничения

Локально пройдены автоматические тесты, сборка, TypeScript и ESLint. Проверено подключение
к настоящему AE и выполнение команд; интерфейс и сброс истории проверены
в браузерном предпросмотре с имитацией AE.

Перед отправкой команд закрывайте диалоги AE. Изменение устраняет постоянные
фоновые запуски скриптов, но не снимает ограничение самого After Effects.
Срок действия не отменяет команду, которая уже начала исполняться.
Проверка сценариев с настоящим открытым диалогом остаётся отдельным этапом;
порядок проверки приведён в [техническом описании](docs/MODAL-SAFE.md#live-acceptance-no-edits-needed).
Установка и работа на macOS не проверялись.

## Откат

Установщик печатает путь к `snapshot.json`. Для восстановления:

```powershell
powershell -NoProfile -File .\install-modal-safe.ps1 -RestoreSnapshot "путь-к-snapshot.json"
```

Затем вернуть прежний путь сервера в MCP-клиенте и перезапустить AE и клиент.
